# روابطي

صفحة روابط عربية للموبايل، مع لوحة تحكم من الموقع نفسه. صاحب الصفحة يسجّل دخول، يعدّل اسمه وصورته وألوانه وروابطه ويضغط «حفظ ونشر». الزوار يرون الملف المحفوظ عبر Netlify Blobs؛ لا يحتاجون حسابًا.

## النشر على Netlify

1. انشر المستودع كـ Netlify site. الإعدادات في `netlify.toml`: البناء `npm run build` والمجلد `dist`، والدوال في `netlify/functions`.
2. أضف `ADMIN_PASSWORD` بكلمة مرور قوية وفريدة من إعدادات Environment variables في Netlify، متاحة لدوال الموقع، ثم أعد النشر. لا تضع كلمة المرور في الكود أو Git أو المحادثة.
3. افتح الموقع واضغط «خصّص صفحتك»، سجّل الدخول بالكلمة التي حددتها، املأ البيانات وارفع الصورة، واضغط «حفظ ونشر».

يتطلب النشر حساب Netlify مصرحًا به وخدمة Netlify Blobs. رفع `dist` فقط بالـ drag-and-drop لا ينشر الدوال؛ استخدم نشر Git أو Netlify CLI للمشروع كاملًا. الموقع يدعم صاحب صفحة واحدًا، وليس خدمة حسابات متعددة. لا توجد استعادة كلمة مرور بالبريد؛ غيّر المتغير في Netlify وأعد النشر عند الحاجة. الصور محفوظة داخل بيانات الملف بحد أقصى ٢ ميجابايت، والروابط بحد أقصى ٥٠.

## التطوير والاختبار

```sh
npm ci
npm run build
node --test tests/profile.test.mjs
```

للتجربة المتكاملة استخدم `netlify dev` بعد تسجيل الدخول وربط الموقع وتعيين `ADMIN_PASSWORD` محليًا بشكل آمن. خادم ملفات ثابتة وحده يعرض التصميم لكنه لا يشغّل الدخول أو الحفظ. خط Cairo الخارجي اختياري ولديه خط بديل.
